# Ceenum Technologies — Website V2

A static, responsive, multi-page digital agency website (no build tools, no paid dependencies).

## Files
- `index.html` — new homepage and interactive 3D-inspired visual
- `services.html` — full services page
- `about.html` — about page
- `contact.html` — form that opens WhatsApp with entered details
- `assets/styles.css`, `assets/app.js` — shared design and behavior

## Preview
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Go live with Netlify
1. Extract the ZIP.
2. In Netlify > Add new site > Deploy manually, drag in the **ceenum-technologies-v2** folder (not the zip itself).
3. Verify all four pages and WhatsApp buttons work.
4. In Netlify Domain management, add your purchased custom domain and follow the DNS steps.

## WhatsApp
